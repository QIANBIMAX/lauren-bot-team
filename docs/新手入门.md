# 新手入门（大白话）

面向：几乎没写过代码的人。  
目标：装好软件、认得三个机器人、用「终端」跑通三个演示，看懂「做完一件事 → 交出去 → 下次别再踩坑」。

> 日期：2026-11-04（Asia/Shanghai）  
> 一期只讲三个角色：幕僚长、开发助手、验证助手。没有 Nancy / Matcha。

---

## 1. 这是什么、能帮你看到什么

这套东西**不是**去改 OpenMausBot（下面简称 OMB）的源码。  
交付给你的是三块：

1. **团队包**（文件夹 `lauren-omb-pack/`）——三个机器人的人设与职责说明，准备进 OMB 用。
2. **工程闭环工具**（文件夹 `lauren-team-kit/`）——管任务状态、验收门槛、合并前检查。
3. **小演示应用**（文件夹 `demo-app/`）——一个很小的「任务列表」程序，专门用来演示筛选、返工、学教训。

你要看懂的，其实是三个环：

| 环 | 白话 |
|---|---|
| 做完一件事 | 有人拆任务 → 有人改代码 → 有人真的跑检查 |
| 交出去 | 检查过了，才允许合到「演示用的本地分支」（不是公司主仓） |
| 下次别再踩坑 | 踩过的坑写成规则；同类问题再出现会被拦住 |

优先：**苹果芯片的 Mac**（一期已在这种机器上测过）。

1. **OpenMausBot 0.1.140**（队工作台软件；Mac 上已实测过这个版本）。

Windows / Linux：**一期尚未在本项目验收通过**，请先用 Mac，或等交付人补充。

## 3. 第一步：安装 OpenMausBot

### 3.1 从哪下

- 找安装包：文件名类似 `OpenMausBot-0.1.140-arm64.dmg`（苹果芯片用 arm64）。
- **找不到安装包时**：直接向交付人索取 DMG，不要随便下别的版本。

### 3.2 怎么装（Mac）

1. 双击 DMG。
2. 把 OpenMausBot 拖进「应用程序」（Applications）。
3. 从启动台或「应用程序」打开它。

### 3.3 怎么确认版本是 0.1.140

建议操作（以你本机 OMB 界面为准）：

- 打开 OMB → 找「关于」「About」或设置里的版本号。
- 或者在 Finder 里：应用程序 → OpenMausBot → 右键「显示简介」，看版本。

本机实测过的安装位置：`/Applications/OpenMausBot.app`，版本 **0.1.140**。  
配套引擎（给机器人调用模型用的那一层）在 Mac 上锁定过：**Codex 0.151.0**。引擎登录若界面有引导，按界面做；细节见交付人说明。

版本不是 0.1.140：**先别硬往下走**，问交付人要对应包，或确认是否允许用你手上的版本。

## 5. 第三步：认识三个机器人各自干什么

把他们想成一个小项目组：

| 角色（英文名仅供对照） | 比喻 | 干什么 | 不干什么 |
|---|---|---|---|
| 幕僚长（chief） | 项目经理 | 听需求、划范围、拆任务、盯状态、汇总结果 | 默认不自己写业务代码 |
| 开发助手（developer） | 写代码的 | 在指定地方改代码、自检、按打回意见修 | 不自己宣布「验收通过」、不直接合主仓 |
| 验证助手（verifier） | 验收的 | 按清单真跑检查、留证据、说通过或不通过 | 默认不改待验收代码、不信「我说过了」 |

一期**只有**这三个。没有 Nancy / Matcha。

他们理想的协作顺序：幕僚长拆好 → 开发助手改 → 验证助手验；验不过就打回修改，不能假装完成。

## 7. 第五步：不靠 OMB 也能先看懂闭环（用终端跑演示）

三个演示脚本已经在本机/真机路径上跑通过，**照着做一般会过**。  
这里教零基础怎么用「终端」。

### 7.1 「终端」是什么？

Mac 自带的一个小程序，名字就叫「终端」（英文 Terminal）。  
你在里面粘贴别人写好的命令，电脑就会按命令干活，并打印出结果。

打开方式（任选）：

- 按 `Command + 空格`，输入「终端」或 `Terminal`，回车；或
- 启动台 → 其他 → 终端。

### 7.2 怎么粘贴命令？

1. 用鼠标选中下文代码框里的整行（或整段）。
2. `Command + C` 复制。
3. 点一下终端窗口，`Command + V` 粘贴。
4. 按键盘「回车」执行。

一次只跑一段。跑完看有没有文档说的「成功字样」。

### 7.3 先进入项目文件夹

把下面整行粘贴进终端，回车（若你的拷贝不在 F 盘，改成你实际路径）：

```bash
cd "/Volumes/F/宁银理财/实习/lauren-bot-team-v0.1"
```

成功时：一般没有大段报错；再输入下面这行，应能看到一串文件夹名（含 `demo-app`、`lauren-team-kit` 等）：

```bash
ls
```

### 7.4 演示 C1（筛选能用）

```bash
cd "/Volumes/F/宁银理财/实习/lauren-bot-team-v0.1/demo-app"
bash scripts/smoke.sh
```

**成功时大概会看到**：最后一行类似 `SMOKE OK`。

### 7.5 演示 C2（弄坏 → 打回 → 修好）

```bash
cd "/Volumes/F/宁银理财/实习/lauren-bot-team-v0.1/demo-app"
bash scripts/smoke-c2.sh
```

**成功时大概会看到**：最后有 `C2 REWORK DEMO OK`（中间会故意失败一轮，那是正常的）。

可选（同一故事，但是走工程工具那一层）：

```bash
cd "/Volumes/F/宁银理财/实习/lauren-bot-team-v0.1"
bash lauren-team-kit/scripts/c2_kit_rework_smoke.sh
```

**成功时大概会看到**：`C2 KIT REWORK SMOKE OK`。

### 7.6 演示 C3（学过的坑下次拦住）

```bash
cd "/Volumes/F/宁银理财/实习/lauren-bot-team-v0.1/demo-app"
bash scripts/smoke-c3.sh
```

**成功时大概会看到**：`C3 LESSON REUSE DEMO OK`。

可选（工程工具层）：

```bash
cd "/Volumes/F/宁银理财/实习/lauren-bot-team-v0.1"
bash lauren-team-kit/scripts/c3_kit_lesson_smoke.sh
```

**成功时大概会看到**：`C3 KIT LESSON SMOKE OK`。

### 7.7 失败了怎么办？

1. **不要慌**，也不要反复乱改文件夹。
2. 把终端里**从你粘贴命令开始到最后**的整段文字全选复制。
3. 发给交付人，并说明：你用的是哪台电脑、OMB 版本（若有）、项目文件夹路径。

脚本会优先用各目录下已有的 `.venv`（一种隔离好的 Python 环境）。若提示找不到 `python3`，见 `docs/安装指南.md`。

## 10. 常见问题

**Q：OMB 版本不是 0.1.140？**  
A：先问交付人。Mac 上钉死测过的是 0.1.140。

**Q：找不到项目文件夹？**  
A：确认 F 盘已挂载；路径含中文「宁银理财」「实习」。用 Finder 点进去，再把路径拖进终端也可以。

**Q：终端说 Permission denied / 没有权限？**  
A：把完整报错发给交付人。不要用网上随便搜的「关闭安全」教程乱关系统保护。

**Q：脚本失败，最后没有 `SMOKE OK` / `… DEMO OK`？**  
A：整段输出发给交付人。常见原因：不在正确目录、Python 没装好、`.venv` 被删。

**Q：OMB 里建不出 bot？**  
A：属「尚未在本项目正式验收」范围。截图 + 版本号发给交付人；可先只跑第五节演示。

**Q：Windows / Linux 能用吗？**  
A：一期**尚未验收**。请先用 Apple 芯片 Mac，或等补充文档。
