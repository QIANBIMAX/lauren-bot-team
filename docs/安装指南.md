# 安装指南（细一点）

面向几乎没写过代码的人。装完软件、放好文件夹、必要时备好 Python，就能跑演示。

> 日期：2026-11-04（Asia/Shanghai）  
> **Windows / Linux：一期尚未在本项目验收通过。** 下文以 Apple 芯片 Mac 为主。

新人总览请先看：`docs/新手入门.md`。

## 1. 安装 OpenMausBot（OMB）

### 1.1 版本钉死（Mac）

| 项 | 要求 | 状态 |
|---|---|---|
| OpenMausBot | **0.1.140** | Mac **已实测** |
| 安装位置（实测） | `/Applications/OpenMausBot.app` | 已确认 |
| 引擎 Codex | **0.151.0**（Mac 锁定） | 已实测锁定 |
| Windows / Linux OMB | — | **待测** |

### 1.2 拿到安装包

- 文件名类似：`OpenMausBot-0.1.140-arm64.dmg`（苹果芯片选 arm64）。
- **找不到时：向交付人索取 DMG**，不要改用未经确认的版本。

### 1.3 安装步骤（Mac）

1. 双击 DMG。
2. 将 OpenMausBot 拖到「应用程序」。
3. 首次打开若系统提示「无法验证开发者」：按系统引导到「系统设置 → 隐私与安全性」允许打开（以你系统界面为准）。
4. 打开应用，完成界面上的初次引导（若有引擎登录 / 权限提示，按界面做）。

### 1.4 确认版本

任选一种你找得到的方式：

- OMB 内「关于 / About / 设置」里的版本号应为 **0.1.140**。
- Finder → 应用程序 → OpenMausBot → 右键「显示简介」。

不是 0.1.140：停下来问交付人。

### 1.5 关于「在 OMB 里建三角色」

把团队包文字贴进三个 bot，属于**建议操作**，**尚未在本项目正式验收通过**（桌面端操作；程序接口写入会被拒）。  
步骤摘要见 `docs/新手入门.md` 第 6 节与 `lauren-omb-pack/README.md`。  
**即使这一步暂时做不了，也不妨碍你先跑第五节的终端演示。**

## 3. Python 与「虚拟环境」（跑演示时）

演示脚本用的是 Python（一种常用的小程序运行环境）。

### 3.1 你需要装系统 Python 吗？

Mac 上通常已有 `python3`。在终端试：

```bash
python3 --version
```

**成功时大概会看到**：一行版本号，例如 `Python 3.12.x` 或 `3.13.x`。  
项目要求大致是 **3.10 及以上**。若提示 `command not found`，向交付人要「如何安装 Python 3」的说明，或让对方帮你装好。

### 3.2 项目里已经备好的环境（优先用这个）

本交付里通常已经带了两个「虚拟环境」（隔离好的 Python，文件夹名 `.venv`）：

| 位置 | 用途 |
|---|---|
| `demo-app/.venv/` | 跑演示应用、C1/C2/C3 烟雾脚本时优先用 |
| `lauren-team-kit/.venv/` | 跑工程闭环工具、kit 烟雾脚本时用 |

C1 的 `scripts/smoke.sh` 会自动：若存在 `demo-app/.venv/bin/python`，就用它。

**你平时照着新手入门复制命令即可，一般不用自己建环境。**

### 3.3 若 `.venv` 丢了或不可用（复制这一行）

只在脚本明确报错、且交付人让你重建时再做。

**重建演示应用环境**（在项目根目录打开终端后，逐行粘贴）：

```bash
cd "/Volumes/F/宁银理财/实习/lauren-bot-team-v0.1/demo-app"
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"
```

**成功时大概会看到**：pip 安装结束没有红色大段报错；然后可以再跑：

```bash
bash scripts/smoke.sh
```

期望最后出现 `SMOKE OK`。

**重建工程工具环境**：

```bash
cd "/Volumes/F/宁银理财/实习/lauren-bot-team-v0.1/lauren-team-kit"
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"
```

**成功时大概会看到**：安装结束无致命报错。可选自检：

```bash
.venv/bin/python -m pytest tests/ -q
```

（本机复验时曾全部通过；你机器上若失败，把输出发给交付人，**不要自己标「已通过」**。）

## 4. 环境变量示例（可选）

项目根目录有示例文件：`.env.example`。

内容大意：

```text
DEEPSEEK_API_KEY=
MERGE_POLICY=confirm
LAUREN_TEAM_ROOT=
```

说明（白话）：

- `MERGE_POLICY=confirm`：默认要人确认才合演示分支（**推荐保持**）。
- `DEEPSEEK_API_KEY`：若某引擎要用密钥才填；**不要把真密钥提交进共享拷贝**。
- `LAUREN_TEAM_ROOT`：有时用来指项目根路径；新手跑烟雾脚本通常**不用**先配这个。

若交付人给了你一份 `.env` 填写说明，按其填写；没有则先空着，只跑演示即可。

复制示例（可选）：

```bash
cd "/Volumes/F/宁银理财/实习/lauren-bot-team-v0.1"
cp .env.example .env
```

然后用文本编辑打开 `.env` 修改。`.env` 里不要塞真实密钥到要外传的拷贝里。

## 5. 装完后的最小验收（推荐）

按顺序跑；任一失败就把终端全文发给交付人。

```bash
cd "/Volumes/F/宁银理财/实习/lauren-bot-team-v0.1/demo-app"
bash scripts/smoke.sh
```

期望：`SMOKE OK`

```bash
bash scripts/smoke-c2.sh
```

期望：`C2 REWORK DEMO OK`

```bash
bash scripts/smoke-c3.sh
```

期望：`C3 LESSON REUSE DEMO OK`

可选加强（工程工具层）：

```bash
cd "/Volumes/F/宁银理财/实习/lauren-bot-team-v0.1"
bash lauren-team-kit/scripts/c2_kit_rework_smoke.sh
bash lauren-team-kit/scripts/c3_kit_lesson_smoke.sh
```

期望分别出现：`C2 KIT REWORK SMOKE OK`、`C3 KIT LESSON SMOKE OK`。
